# Security Policy

If you believe you have found a security vulnerability in StepMania, please
report it privately through GitHub's security advisory flow for this
repository.

Do not post exploit details in a public issue unless the vulnerability has
already been disclosed or the report has been routed through a private channel.

If the private advisory flow is unavailable, open a normal issue with a short
description and clearly mark it as a security report so it can be handled
carefully.
